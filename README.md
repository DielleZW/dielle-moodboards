# Dielle Design Studio — reusable wedding moodboard

## Preview
Open `index.html` in a browser with an internet connection (sample images are hosted online).

## Personalise for a client
Edit `client-config.js` to change names, date, venue, vision, palette, sections and image URLs. For your own photos, create an `images/` folder and use paths like `images/ceremony.jpg`. Duplicate the entire folder for each client.

## Publish with GitHub Pages
Create a new GitHub repository and upload `index.html`, `client-config.js`, and your `images/` folder if used. In repository Settings > Pages, choose Deploy from a branch, branch `main`, folder `/ (root)`, and save. Your website will be published at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Important
This starter is a static website. It has no client login, approvals, comments or content management dashboard. GitHub Pages websites are public; do not upload private client details. Sample photographs are temporary external placeholders: replace them with images you have permission to use before sharing with clients. Design is original and inspired by the referenced board's general section structure, not a copy of its source code.
